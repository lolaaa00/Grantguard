# Live demo

1. Connect an injected EIP-1193 wallet and switch to Studionet chain 61999.
2. Open the demo grant round.
3. Submit a proposal with a public repository, milestones, budget, and HTTPS evidence.
4. Run consensus review and confirm criterion-level scores.
5. Challenge a qualified proposal or wait for the challenge window.
6. Finalize the surviving proposal, inspect the certificate, and withdraw the native GEN award.
